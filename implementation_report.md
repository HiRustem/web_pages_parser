# Отчёт об реализации: AI Browser Agent (HH.ru)

## Цель
Автоматизированный сбор вакансий с hh.ru: поиск по названию, парсинг списка, парсинг деталей вакансий, сохранение результатов.

## Реализованные компоненты

### 1. Поисковый флоу (`main.py`)
- **Навигация**: Устойчивая навигация с обработкой попапов (cookies, телефон) через иерархию селекторов.
- **Поиск**: Программный `form.submit()` вместо кликов (решение проблемы перехвата событий).
- **Lazy Loading**: Функция `wait_for_results` (скролл + проверка стабилизации DOM) обеспечивает сбор 100% найденных вакансий.

### 2. Парсинг данных
- **`vacancy_parser.py`**: Сбор списка (название, ссылка) через `page.evaluate()`, отсеивание рекламы.
- **`vacancy_detail_parser.py`**: Глубокий парсинг вакансии (Зарплата, Опыт, Город, Формат, Описание, Навыки).

### 3. Обработка данных и сохранение
- **`vacancy_writer.py` / `details_writer.py`**: Формирование отчётов в TXT + JSON.
- **Валидация**: Защита от дублей, отсутствующих полей (`null`), битых ссылок (`error` в JSON).

### 4. Инфраструктура
- **Автотесты**: 25 автотестов (pytest + playwright).
    - Юнит: валидация данных, парсинг ЗП/формата, sanitize имён файлов.
    - E2E: навигация, поиск, сбор, полный флоу.

## Устранённые проблемы
1. **Динамический контент**: Lazy loading (скролл) решил проблему недосбора вакансий (с 20 до 32+).
2. **Селекторы**: Переход от LLM-гадания к фиксированным селекторам (`[data-qa]`) обеспечил 100% стабильность.
3. **Клик-интерцепция**: Программный `submit` формы вместо `click` убрал ошибки взаимодействия.
4. **Региональность**: Учёт `kazan.hh.ru` (использование относительных путей для ссылок).
