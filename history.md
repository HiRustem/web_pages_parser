# История разработки AI Browser Agent

## Цель проекта
Создать AI-агента на Python, способного взаимодействовать с браузером (Playwright) для выполнения задач пользователя (поиск вакансий, навигация), используя локальную LLM (COMBA) для принятия решений.

## Основные этапы и проблемы

### 1. Начало: Node.js (папка AI_Hands)
- **Результат**: Неудачно.
- **Причина**: Проблемы с парсингом JSON-ответов от API (получение HTML вместо ожидаемого JSON) и отсутствие устойчивого взаимодействия с LLM.

### 2. Переход на Python (папка Python_AI_Agent)
- **Результат**: Частичный успех с инструментарием, неудача с автоматизацией.
- **Проблемы**:
    - **API**: Сложности с обработкой потоковых ответов (streaming) от API, пришлось принудительно отключать `stream`.
    - **Селекторы**: Нестабильная работа с элементами на сайте hh.ru. Динамические элементы (попапы, выпадающие списки автодополнения) перехватывали клики и блокировали действия.
    - **Логика**: Агент часто сообщал об успехе действия, хотя оно не было выполнено (например, текст в поле ввода не появлялся, кнопка поиска не нажималась).
    - **Контекст**: Агент часто терял контекст или зацикливался, повторяя свои предыдущие фразы.

## Почему не удалось достичь автоматизации
- **Сложность UI**: Современные сайты (hh.ru) активно используют динамические элементы, которые сложно предсказать без "человеческого" контроля.
- **Отсутствие обратной связи**: Агент принимал решения "вслепую" (на основе селекторов, которые могли измениться или быть невидимыми), не имея возможности надежно проверить результат действия (например, "ввод выполнен успешно").
- **Зацикливание**: Несовершенство промптов и управления историей диалога приводило к повторению действий или слов.

## Вывод
Проект продемонстрировал, что создание полностью автономного агента для взаимодействия со сложными динамическими сайтами требует:
1. Гораздо более сложной обработки исключений при взаимодействии с UI.
2. Механизмов визуальной верификации (скриншоты + анализ зрения модели).
3. Более гибкой системы промптов для работы с DOM-структурой.
